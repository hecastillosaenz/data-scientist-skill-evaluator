# Reglas de Apoyo y Nivel

## Apoyo (por etapa, R5)

- **Guiado**: se muestra el paso sugerido.
- **Pistas**: se habilita el botón "Ver pista".
- **Autónomo**: sin ayudas.

El Apoyo se fija de forma independiente en cada etapa.

## Nivel

- Mientras una etapa esté en Guiado o Pistas, su Nivel no sube (R6).
- Abrir el toggle de Solución marca el intento como "Con ayuda" sin importar el resultado (R7).
- El alcance de "Nivel del usuario" (Trainee → Básico → Intermedio → Avanzado) sigue **sin decidir** (SDD §7.3).
